# GIC/GCC Annual Report 2025–2026 — FINAL

Complete website upload package for the new `annual-report-2025-2026` repository.

## Upload with GitHub Desktop

1. Clone the NEW repository into a new folder on your computer.
2. Extract this ZIP. Open the extracted folder until you see `index.html`.
3. Copy ALL files and folders from that folder into your newly cloned repository folder. Replace its initial README when prompted.
4. In GitHub Desktop, commit the changes to `main`, then click **Push origin**.
5. On GitHub.com, choose **Settings > Pages > Deploy from a branch > main > /(root) > Save**.
6. After deployment completes, click **Visit site** and test navigation, video playback and the PDF download.

## Files

- `index.html`: website entry page; opens the final report automatically.
- `GIC_GCC_Annual_Report_2025-2026_FINAL.html`: final interactive annual report.
- `events.html`, `committees.html`, `yearbook.html`: required chapter panels.
- `assets/`: all images and fonts.
- `downloads/GIC_GCC_Annual_Report_2025-2026_FINAL.pdf`: complete, valid 41-page PDF.
- `downloads/GIC_GCC_Business_Confidence_Survey_2026_Report_v0.17.pdf`: survey download.
- `.nojekyll` and `.gitignore`: supporting repository files.

Upload everything in this package. All filenames and download links are already configured. GitHub Desktop supports this package's complete PDF file.
